# Annual Maintenance

This is a simple yearly pass for a personally controlled machine.

## 1. Run a full read-only check

```powershell
.\boring-admin.ps1 check
```

Read the warnings before doing anything else.

## 2. Review software intentionally

Check whether your local profile still reflects what you actually want.
Remove dead package ideas instead of carrying stale intent forever.

## 3. Review recovery readiness

Confirm:

- data backup still exists
- account recovery still works
- BitLocker recovery material is still reachable

## 4. Review updates and reboot state

Do not interpret pending reboot signals as harmless noise.
Clear the obvious maintenance backlog first.

## 5. Resolve or document warnings

If a warning is still open at the end of the review,
either address it or record for yourself why you are accepting it.
