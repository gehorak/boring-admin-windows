# boring-admin-windows česky

Tahle česká část je praktický rozcestník
pro technicky zdatného člověka,
který chce rozumně spravovat vlastní Windows počítač
bez zbytečného kouzlení.

Projekt stojí na jednoduchém pořadí:

- nejdřív `check`
- potom `plan`
- až nakonec `apply`

První bezpečný krok:

```powershell
.\boring-admin.ps1 check
```

Když si nejsi jistý, zastav se.
